## 新能力的接入边界

V2 项目适配器可在 `map_agent_output` 中声明 `output_status=error` 及字符串 `error_type`、`error_message`。引擎保留完整输出和成功兄弟样本；含错误评分样本的 execution 封存为 technical_failure。Run completed 表示评测结束，不证明全样本成功；业务 passed/failed/unknown 独立处理。

省略状态的旧 mapper 继续默认 ok，兼容性不等于覆盖了业务内部错误。手术项目现有私有适配器仍需按新契约将 RETRYABLE_FAILED / LLM_TIMEOUT 映射出来，后续执行才会进入技术失败摘要。历史 v2 的外层 ok 不会被反写修正；本轮未改其 CSV、哈希或判定。摘要的零仅表示没有已上报的 error，不认证任意 JSON 内都没有隐含失败。

`--ids ID...` 先校验全部 ID，再按 canonical 顺序筛选并应用 offset/limit，分组执行保留完整上下文。它与 only-failures 互斥，缺 ID 不回退全量；技术错误和 unknown 不自动混入业务失败表。旧自管 runner 使用显式 ID 前需迁移。

源码版本仍为 2.2.0，本轮未发布、未重装全局 CLI 或当前会话插件；使用全局命令前按 README 的源码安装方式更新，不能仅按相同版本号判断是否已含修复。
